# baked. ReSkate profiles

Mod profiles for skating on the baked. ReSkate servers. Import one into ReSkateLauncher and you get the same maps and cosmetics we run.

## How do I use these?
1. Download the profile you want (a `.r2z` file) from its **Download** link below, or from the [latest release](https://github.com/xThrasherrr/ReSkateBakedProfiles/releases/latest).
2. Open ReSkateLauncher.
3. Go to **Profiles**.
4. In the **Import** section, click **Import File** and pick the `.r2z` you downloaded.

Stuck? Ask in our [Discord](https://discord.bakedskate.org).

## Adding or updating a profile
Export the profile from ReSkateLauncher, save it in `profiles/` with no spaces in the name (e.g. `baked-base-pack.r2z`), add a section above, and push to `main`. A new release with every profile attached is published automatically.
